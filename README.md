# 🛒 GoCart – Fullstack E-Commerce Website

![gocart](./assets/preview.png)

## 📌 Overview

**GoCart** is a full-stack e-commerce web application inspired by Amazon. It provides a complete online shopping experience including product browsing, cart management, secure authentication, and order processing.

This project is built using modern web technologies and demonstrates real-world e-commerce functionality.

---

## 🚀 Tech Stack

* **Frontend:** Next.js (React), Tailwind CSS
* **Backend:** Next.js API Routes (Node.js)
* **Database:** Prisma ORM + SQL (PostgreSQL/MySQL)
* **Authentication:** JWT / Session-based
* **Tools:** Git, GitHub, Postman

---

## ✨ Features

* 🛍️ Product listing & search
* 🔐 User authentication (Login/Register)
* 🛒 Add to cart & cart management
* 💳 Checkout system
* 📦 Order management
* 👤 User profile
* 🛠️ Admin dashboard (manage products/orders/users)

---

## ⚙️ Installation & Setup

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/S-Harshni/Amazon-Clone-MernStack.git
cd gocart-nextjs-ecommerce
```

---

### 2️⃣ Install Dependencies

```bash
npm install
```

---

### 3️⃣ Setup Environment Variables

Create a `.env` file in root and add:

```env
DATABASE_URL=your_database_url
NEXTAUTH_SECRET=your_secret
```

---

### 4️⃣ Setup Database (Prisma)

```bash
npx prisma migrate dev
npx prisma generate
```

---

### 5️⃣ Run the Project

```bash
npm run dev
```

👉 Open: http://localhost:3000
